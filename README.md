Repositorio dedicado al trabajo realizado en la asignatura **Desarrollo Web en Entorno Servidor**, del ciclo de Desarrollo de Aplicaciones Web (DAW).

## 📚 Contenido

En este repositorio se recopilan los materiales y las actividades desarrolladas durante la asignatura:

- Apuntes y materiales de estudio.
- Ejercicios prácticos.
- Prácticas realizadas durante el curso.

## 🎯 Objetivo

Organizar y mantener los trabajos de la asignatura en un único lugar, documentando mi proceso de aprendizaje y la evolución de mis conocimientos en desarrollo web del lado del servidor.
